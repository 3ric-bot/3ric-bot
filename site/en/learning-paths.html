Frontend Developer Path

This 14-week journey connects accessibility, JavaScript, React, and career prep with evidence-of-mastery checkpoints.

Week 1–4 · Web Foundations

Ship semantic layouts, run accessibility audits, and explain the WHY to stakeholders.

Week 5–8 · JavaScript Essentials

Model async flows, critique trade-offs in code reviews, and document impact.

Week 9–12 · React Foundations

Build stateful UIs with clarity, introduce testing, and justify your architecture.

Week 13–14 · Job Readiness

Deliver a capstone, publish a reflection, and receive mentor-backed feedback.
