Guardrails that ship with every campaign

  • Every create/update/write operation triggers an audit log entry with actor, IP, and user agent metadata.
  • Promotion values are validated (percentage ≤ 100, fixed ≥ €1) and plan keys must exist before persisting.
  • Activation requires an explicit POST and automatically adjusts start times so dormant codes never go live by accident.
  • Archived promotions are excluded from default queries, preventing stale codes from resurfacing.

Need deeper governance? Connect the `/admin/audit-log` and `/admin/privacy-requests` endpoints to your SIEM.
