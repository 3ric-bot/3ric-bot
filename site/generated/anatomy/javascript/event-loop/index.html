Waarom het belangrijk is

Door de event loop te begrijpen schrijf je UI's die responsief blijven onder druk.

Runtime inzichten

  • Microtasks (Promises) draaien altijd voor rendering.
  • Timers met dezelfde delay kunnen in verschillende ticks landen door queue prioriteit.
  • Langdurige sync taken blokkeren alle andere events.

Veelgemaakte valkuilen

  • Te veel microtasks veroorzaken starvation
  • Onbegrip over render fase leidt tot layout thrashing
