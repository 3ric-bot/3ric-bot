Closures ontrafeld

Analyseer hoe lexical scope en runtime gedrag samenwerken om closures mogelijk te maken.

Bekijk het volledige leerpad

Waarom het belangrijk is

Closures bepalen hoe state wordt vastgehouden in UI componenten, event handlers en module-patterns.

Runtime inzichten

  • De scope chain wordt opgebouwd tijdens parse-time, niet tijdens uitvoering.
  • Elke functie call krijgt een nieuw closure-record met verwijzing naar outer scope.
  • Garbage collection kan variabelen pas vrijgeven als er geen referenties meer zijn.

Veelgemaakte valkuilen

  • Onverwachte memory leaks door langdurige references
  • Verwarring tussen var/let in loops met async callbacks
