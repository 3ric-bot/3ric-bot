Fetch API cheatsheet

Herhaal de belangrijkste patronen voor het werken met fetch, inclusief foutafhandeling en retries.

Waarom dit relevant is

Consistente data calls voorkomen race conditions en verlagen supportdruk.

Basisrequest

fetch(url, { headers: { 'Content-Type': 'application/json' }})
  .then(res => { if (!res.ok) throw new Error('Response error'); return res.json(); })

Zorg dat je altijd `res.ok` controleert om silent failures te vermijden.

Retry met exponential backoff

async function retry(fn, attempts = 3) {
  for (let i = 0; i < attempts; i++) {
    try {
      return await fn();
    } catch (error) {
      await new Promise((resolve) => setTimeout(resolve, 2 ** i * 100));
    }
  }
  throw new Error('Max retries reached');
}

Backoff voorkomt dat je API extra belast tijdens incidenten.
