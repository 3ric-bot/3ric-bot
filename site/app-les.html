Les: React useEffect patronen

Leer hoe je side-effects beheert met dependency arrays, cleanup functies en custom hooks.

1. Recap

useEffect voert side-effects uit na render. Bepaal gedrag met dependency array.

{`useEffect(() => {
  const subscription = api.subscribe();
  return () => subscription.unsubscribe();
}, [api]);`}

2. Guided practice

Pas de dependency array aan zodat het effect alleen opnieuw runt als userId verandert.
